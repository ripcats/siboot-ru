# siboot

Установка SideInstaller на iPhone с iOS 27 или новее — прямо из Open Minis, без компьютера. Проект основан на [SideInstaller](https://github.com/FrizzleM/SideInstaller); русская версия и её поддержка — ripcats.

Для доступа к серверам Apple обычный VPN может быть необходим: без него вход или установка могут завершиться тайм-аутом либо ошибкой. siboot не проверяет и не переключает VPN — переключение выполняется вручную по подсказкам программы.

- [Установка и работа в Open Minis](minis/README.md)
- [Дополнительное сопряжение через rootshell](rootshell/README.md)

Проект поддерживает [ripcats](https://github.com/ripcats).
